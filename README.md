## 📖 Overview

**AETHER** is a high-converting agency landing page template engineered to break away from generic AI-generated layouts. It pairs rich visual hierarchy and dark glassmorphism aesthetics with dynamic HTML5 canvas particle physics, smooth micro-interactions, live design system customization, and a real-time ROI project cost estimator.

---

## ✨ Key Features

- **🌐 Dynamic Canvas Physics**: Real-time particle network reacting dynamically to cursor position and hover proximity.
- **🎛️ Live UI Token Customizer**: Floating widget drawer allowing instant adjustments to primary accent hues, glass blur opacity, glow intensity, and corner radii via dynamic CSS variables.
- **🧮 Interactive ROI & Cost Estimator**: Live project budget calculator with scope selectors, feature add-ons, motion depth sliders, and projected ROI output.
- **🖼️ Asymmetrical Bento Grid**: Portfolio work organized by category (SaaS Apps, AI Interfaces, Web3 Platforms) with interactive case study modals.
- **🎚️ 3D Tilt Card Component**: GPU-accelerated 3D tilt card in the hero section displaying live performance metrics.
- **🔍 Searchable FAQ Accordion**: Instant real-time filtering for common client inquiries and engagement details.
- **📦 In-Browser ZIP Source Code Exporter**: In-browser archiving powered by `JSZip` and `FileSaver.js` allowing visitors to download the full template bundle directly.
- **📱 Fully Responsive**: Fluid, mobile-first design using Tailwind CSS utility classes.
